# FORTIS Markdown Editor

Настольный markdown-редактор: работа с папкой как с рабочим пространством, вкладки,
визуальный режим и режим разметки, поиск по папке, сравнение файлов, история версий,
формулы, экспорт и импорт. Работает без интернета.

## Запуск после клонирования

Нужны Git и [актуальная LTS-версия Node.js](https://nodejs.org) — не ниже
22.12.0. Команда одинакова в PowerShell, командной строке Windows и терминалах
macOS/Linux:

```bash
git clone <адрес-репозитория>
cd FORTIS_MARKDOWN
npm start
```

Больше ничего устанавливать вручную не надо. При первом запуске команда проверит
окружение, поставит точные зависимости из `package-lock.json`, скачает Electron
для текущей системы и откроет редактор. Первый запуск требует интернет и может
занять несколько минут; следующие работают без сети, пока зависимости не изменятся.

После обновления проекта закройте FORTIS и выполните:

```bash
git pull
npm start
```

Если обновились только исходники, приложение откроется сразу. Если изменились
зависимости, `npm start` сам приведёт их к состоянию выбранного коммита. Команда
не выполняет Git-операции, не устанавливает программу в систему и держит терминал
открытым до закрытия окна FORTIS.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `app/index.html` | Само приложение — собранная страница редактора со всеми библиотеками внутри |
| `app/main.js` | Главный процесс Electron: окно, меню, разрешения, экспорт в PDF |
| `app/preload.js` | Мост между окном и главным процессом |
| `src/` | Исходник прототипа: разметка интерфейса и вся логика в одном файле |
| `docs/` | Описание прототипа и исходные требования к функционалу |
| `scripts/start.js` | Единый launcher: готовит зависимости и запускает Electron |
| `AGENTS.md` | Инструкция запуска и проверки для ИИ-агента |

## Чем настольная версия отличается от браузерной

- **Сохранение в файл без диалога.** `Ctrl+S` (на Mac `Cmd+S`) пишет прямо в открытый
  файл в любой системе. В браузере так умеют только Chrome и Edge, а Firefox и Safari
  скачивают копию.
- **Экспорт в PDF одним шагом.** Вместо системного диалога печати сразу открывается
  сохранение файла. Размер страницы, ориентация и поля берутся из настроек экспорта
  в самом редакторе.
- **Своё окно.** Размер и положение запоминаются между запусками, приложение живёт
  в доке и панели задач отдельно от браузера.

Данные редактора (открытая папка, вкладки, настройки, история версий) хранятся
в профиле приложения, а не в браузере, и не теряются при очистке истории.

## Горячие клавиши

На macOS вместо `Ctrl` — `Cmd`.

| | |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+Shift+O` | новый файл, открыть файл, открыть папку |
| `Ctrl+S` / `Ctrl+Shift+S` | сохранить, сохранить как |
| `Ctrl+W` | закрыть вкладку |
| `Ctrl+F` / `Ctrl+Shift+F` | поиск и замена, поиск по папке |
| `Ctrl+E` / `Ctrl+Shift+E` | режим разметки, разделённый просмотр |
| `Ctrl+B` / `Ctrl+J` | дерево файлов, панель документа |
| `Ctrl+D` | сравнение файлов |
| `Ctrl+R` / `Ctrl+Shift+N` | недавние, шаблоны |
| `Ctrl+Shift+H` | снимок версии |
| `Ctrl+Shift+X` / `Ctrl+Shift+I` | экспорт, импорт |
| `Ctrl+Shift+P` | оформление |

Набор настраивается в самом редакторе.

## Работа с таблицами

Правой кнопкой по любой ячейке открывается меню: добавить строку выше или ниже,
столбец слева или справа, объединить с правой или нижней ячейкой, разъединить,
удалить строку, столбец или всю таблицу. Те же действия есть в панели, которая
появляется над таблицей.

Ширину столбца можно тянуть: подведите указатель к правой границе ячейки —
он превратится в двустороннюю стрелку — и тяните.

Важная оговорка: ни объединения, ни заданную ширину столбцов разметка markdown
выразить не может — в ней нет ни `colspan`, ни `rowspan`, ни ширины. Поэтому
таблица, в которой есть хоть одно объединение или растянутый столбец,
сохраняется в файл как HTML вместо строк с вертикальными чертами. Внутри
редактора и в экспорте она выглядит и работает одинаково, но такой файл могут
не понять сторонние средства просмотра markdown. Как только объединения сняты,
а ширины не заданы, таблица снова сохраняется обычной разметкой.

## Оформление

Пятнадцать вариантов, `Ctrl+Shift+P`. Шесть палитр меняют только цвета
(Nocturne, Уголь, Индиго, **Тайга**, **Кобальт**, **Сепия**, Светлая, Бумага,
Классика), шесть стилей меняют ещё и шрифты, размеры и форму панелей
(Терминал, Печатная страница, Студия, Офис, Неон, Дзен).

Картинка на карточке — миниатюра самого окна: лента сверху, дерево файлов
слева, документ с заголовком и строками текста. По ней видно не только цвет
фона, но и как соотносятся панели с текстом.

## Ограничения

- Доллары распознаются как формула только вплотную к содержимому: `$E = mc^2$`
  формула, а «цена $100 и $200» — обычный текст. Так же считают KaTeX и Pandoc.
- Формулы в экспортированных HTML и PDF оформляются стилями KaTeX с внешнего CDN,
  поэтому без интернета такой документ покажет формулы неоформленными. В самом
  редакторе формулы работают офлайн.
- Не сделано: диаграммы Mermaid, Git, Confluence, живые данные Jira, экспорт в DOCX,
  локализация, плагины.

## Как это устроено

Окно грузится не с `file://`, а по собственной схеме `fortis://app`, объявленной
безопасной. Из-за этого работают `localStorage`, IndexedDB и File System Access API —
те самые, на которых держатся рабочее пространство, вкладки и прямое сохранение.

Экспорт в PDF редактор делает через скрытый `iframe` и `print()`. Настольная версия
перехватывает этот вызов в `app/preload.js` и отдаёт собранный документ главному
процессу, который печатает его в PDF и предлагает сохранить. Если перехват почему-то
не сработает, вызывается обычная печать — то же поведение, что в браузере.
