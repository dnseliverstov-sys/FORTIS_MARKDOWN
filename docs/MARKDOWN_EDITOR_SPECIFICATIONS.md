# FORTIS WYSIWYG Markdown Editor — описание функционала и интерфейса

> Документ описывает, что делает приложение, с точки зрения пользователя и функциональности.
> Намеренно не содержит технических деталей реализации. Предназначен для коллеги, который
> будет создавать аналогичное приложение.

---

## 1. Назначение приложения

**FORTIS WYSIWYG Markdown Editor** — **кроссплатформенное** настольное приложение для
просмотра и редактирования Markdown-файлов в наглядном визуальном режиме (WYSIWYG).
Поддерживаемые операционные системы: **Windows, Linux, macOS**. Пользователь работает
с документом так же, как в текстовом процессоре, а в основе лежит универсальный формат
Markdown, что позволяет использовать подготовленные материалы для публикации в Bitbucket
Data Center и других системах, поддерживающих этот формат.

Приложение рассчитано на:
- редактирование технической документации и `README`-файлов,
- подготовку описаний задач, комментариев и материалов для корпоративного репозитория,
- работу сразу с несколькими файлами и целыми рабочими пространствами (папками).

Для быстрого старта в приложении предусмотрены встроенные **примеры** — демонстрация
возможностей и обучающий материал, помогающий освоиться с основными функциями.

## 2. Основные возможности

### 2.1. Работа с файлами

- **Новый файл** — создание новой безымянной вкладки с пустым содержимым; имя файла запрашивается при первом сохранении (кнопка на панели управления и пункт меню «Файл → Новый», Ctrl+N).
- **Открытие отдельного файла** — пользователь выбирает любой `.md`-файл и открывает его в отдельной вкладке.
- **Работа с рабочим пространством (папкой)** — открытие целой директории: слева отображается дерево файлов, по которому можно перемещаться и открывать файлы двойным кликом.
- **Множественные вкладки** — одновременно открыто несколько файлов; переключение между ними — кликом по вкладке.
- **Сохранение** — запись изменений в текущий файл (кнопка на панели управления и пункт меню «Файл → Сохранить», Ctrl+S). Если файл ещё не связан с путём — открывается диалог «Сохранить как».
- **Сохранение как** — запись текущего файла под новым именем или в другую папку (кнопка на панели управления и пункт меню «Файл → Сохранить как…», Ctrl+Shift+S). Всегда запрашивается новое имя/путь, после записи обновляется привязка вкладки.
- **Индикация несохранённых изменений** — файл с несохранёнными правками помечается специальным значком (в названии вкладки, в заголовке и панели управления).
- **Предупреждение о потере данных** — при попытке закрыть вкладку или само приложение с несохранёнными изменениями появляется запрос подтверждения.
- **Обнаружение изменения файла извне** — если открытый файл изменился в файловой системе (например, другим процессом), приложение уведомляет и предлагает выбрать: сохранить свою версию или загрузить версию с диска.
- **Список недавних файлов и рабочих пространств** — приложение запоминает последние открытые файлы и папки, предлагая их для быстрого повторного открытия.
- **Автоматическое открытие файла при запуске** — при запуске можно указать путь к файлу, и он открывается автоматически.
- **Перетаскивание файлов** — открытие файлов в окно перетаскиванием (drag & drop).
- **Поиск по рабочему пространству** — поиск текста по всем файлам папки с показом результатов.
- **Закладки и «избранные» файлы** — для быстрого доступа.
- **Сравнение файлов (diff)** — наглядное сравнение двух версий или двух файлов.
- **История версий файла внутри приложения** — возможность вернуться к предыдущему состоянию.
- **Автосохранение** — запись изменений в фоне с возможностью восстановления черновика после сбоя.
- **Мастер восстановления после аварийного завершения** — при повторном запуске предлагается восстановить несохранённые данные.
- **Умный «конфликт» при внешнем изменении файла** — подробная сводка различий перед выбором версии (уточнение пункта «Обнаружение изменения файла извне»).

### 2.2. Редактирование Markdown

- **Два режима работы с документом:**
  - **WYSIWYG (визуальный)** — содержимое отображается в отформатированном виде, изменения вносятся с помощью панели форматирования.
  - **Разметка (Markup)** — содержимое отображается в виде исходной Markdown-разметки для точной правки текста.
- **Переключатель режимов** — лёгкий переход между визуальным режимом и исходной разметкой.
- **Режим разделённого просмотра** — две области одновременно (например, «разметка + визуальный», или два файла рядом).

#### Расширенное редактирование

- **Поиск и замена** по тексту в пределах файла (и во всём рабочем пространстве) — с учётом регистра и всей разметки.
- **Проверка орфографии** (встроенная или подключённая) с подчёркиванием ошибок.
- **Автодополнение Markdown-синтаксиса** — подсказки при вводе заголовка, списка, ссылки, кода.
- **Поддержка формул** (математических выражений) в документах.
- **Диаграммы (Mermaid)** — вставка и предпросмотр схем прямо в документе.
- **Оглавление документа** — автоматическое формирование и быстрая навигация по заголовкам.
- **Статистика документа** — количество слов, символов, заголовков, списков.

### 2.3. Форматирование текста (визуальный режим)

Доступные операции форматирования:
- **Заголовки** разных уровней.
- **Стили текста:** жирный, курсив, зачёркнутый.
- **Списки:** маркированные и нумерованные, в том числе вложенные.
- **Списки задач** (отмеченные чекбоксы).
- **Таблицы.**
- **Цитаты.**
- **Ссылки** — внешние и внутренние.
- **Код:** инлайн-код и блоки кода с указанием языка.
- **Информационные блоки (алерты/заметки):** NOTE, TIP, IMPORTANT, WARNING, CAUTION — для выделения важных примечаний.
- **Вставка изображений** — по ссылке или из файла, с автоматическим формированием Markdown-кода.
- **Горизонтальные разделители** и прочие базовые элементы разметки.

> Поддерживаемый набор элементов ориентирован на совместимость с Bitbucket Data Center:
> всё, что подготовлено в редакторе, корректно отображается и в этом корпоративном хранилище.

#### Дополнительные стили («прямое форматирование»)

Панель «прямого форматирования» для выделенного текста: **цвет, подчёркивание, выделение
маркером** — как дополнительные стили к базовым операциям форматирования.

### 2.4. Интерфейс

Окно приложения условно делится на несколько областей:

1. **Главное меню** (верхняя строка приложения): разделы «Файл», «Правка», «Вид», «Окно».
2. **Панель управления (ToolBar)** — ряд кнопок с иконками для основных операций.
3. **Панель инструментов редактора** — кнопки форматирования для визуального режима (заголовки, стили, списки, таблицы и т.д.).
4. **Дерево рабочего пространства** — слева, если открыта папка; позволяет переходить по файлам.
5. **Вкладки открытых файлов** — над областью редактирования.
6. **Область редактирования** — основное поле для документа.
7. **Индикатор состояния** — имя активного файла и пометка о несохранённых изменениях.

Приложение одинаково работает на **Windows, Linux и macOS**: единый набор возможностей,
одинаковый внешний вид и поведение; отличие лишь в привычных для каждой ОС сочетаниях
клавиш и способах управления окном.

#### Настройки и персонализация

- **Темы оформления** — светлая/тёмная, корпоративная, с возможностью настройки.
- **Локализация интерфейса** — поддержка нескольких языков.
- **Настройка горячих клавиш** — переназначение сочетаний под личные предпочтения.
- **Шаблоны документов** — готовые заготовки (README, задание, отчёт, описание) для быстрого старта.
- **Плагины/расширения** — возможность сторонних команд добавлять новые форматы и возможности.
- **Запоминание состояния сеанса** — при следующем запуске автоматически восстанавливаются открытые файлы и папки.

### 2.5. Гибкое управление полезным пространством окна

Приложение предоставляет гибкие средства управления отображением главного меню и панели
управления, что позволяет освободить больше места под область редактирования.

1. **Расширенная панель управления (ToolBar):**
   - кнопки панели полностью соответствуют всем пунктам главного меню (помимо уже существующих операций с файлами);
   - в панели есть кнопка, включающая/отключающая отображение главного меню.
2. **В главном меню** доступны пункты:
   - включение/отключение отображения самого меню;
   - включение/отключение панели управления под меню.
3. **Допустимые сочетания видимости** (инвариант — хотя бы один элемент всегда виден):

   | Состояние | Меню видно | Панель управления видна | Допустимо |
   | --- | --- | --- | --- |
   | Оба видны | да | да | ✅ |
   | Видно только меню | да | нет | ✅ |
   | Видно только панель | нет | да | ✅ |
   | Оба скрыты | нет | нет | ❌ недопустимо |

### 2.6. Работа с системой контроля версий (GIT)

В редактор встроены базовые действия по управлению версиями файлов, хранящихся
в репозитории.

1. **Подключение репозитория** — в рабочем пространстве задаётся удалённый репозиторий, который можно клонировать или открыть прямо из приложения.
2. **Просмотр истории изменений** — окно или панель, показывающая:
   - список коммитов,
   - список веток,
   - комментарии к коммитам,
   - изменённые файлы и суть правок.
3. **Быстрые действия с репозиторием**:
   - кнопка **Commit** — фиксирует текущие изменения,
   - поле для ввода **комментария к коммиту**,
   - кнопка **Push** — отправляет изменения в удалённый репозиторий.
4. **Просмотр pull request** — список открытых pull request по репозиторию с переходом к связанным изменениям.
5. **Синхронизация документации** — подготовленные в редакторе документы (например, `README.md`) могут публиковаться в репозиторий через стандартные команды Git.

### 2.7. Интеграции с Atlassian (Confluence, Jira) и Bitbucket/Git

Редактор является единой точкой работы с документацией: материалы готовятся
и редактируются локально, а затем согласуются с корпоративными системами.

#### 2.7.1. Интеграция с Confluence

- **Скачивание страниц** — пользователь указывает страницу (адрес или страницу из Confluence), приложение загружает её содержимое и отображает в редакторе для правки.
- **Конвертация в Markdown** — содержимое страницы Confluence автоматически преобразуется в Markdown-разметку, пригодную для дальнейшего редактирования и хранения в репозитории.

#### 2.7.2. Интеграция с Jira

- **Связка ключей задач** — упоминания задач вида `PROJ-123` автоматически превращаются в кликабельные ссылки на соответствующие задачи в Jira.
- **Вставка ссылок на задачи** — быстрая вставка ссылки на конкретную задачу (с её названием и статусом) прямо в текст.
- **Ссылки на pull request** — автоматическое распознавание и оформление ссылок на pull request Bitbucket в формат, понятный Jira/Bitbucket.
- **Подсказки при вводе** — при наборе `PROJ-` или `@` пользователю показываются подсказки с существующими задачами и пользователями для быстрого выбора.
- **Экспорт описания** — подготовленное в редакторе описание (например, текст задачи, отчёта или комментария) можно скопировать или отправить как описание задачи в Jira.

#### 2.7.3. Интеграция с Bitbucket/Git

- **Клонирование и открытие репозитория** — в рабочем пространстве задаётся удалённый репозиторий, который можно клонировать и открыть прямо из приложения (см. также раздел 2.6).
- **Просмотр истории и веток** — панель с коммитами, ветками, комментариями и списком изменённых файлов.
- **Быстрые действия** — кнопки Commit, Push и поле для комментария к коммиту.
- **Просмотр pull request** — список открытых pull request по репозиторию с переходом к связанным изменениям.
- **Синхронизация документации** — подготовленная в редакторе документация может публиковаться в репозиторий (файлы `README.md` и др.) через стандартные команды Git.


### 2.8. Импорт и экспорт форматов файлов

Приложение обеспечивает свободный обмен документами с другими инструментами: принимает уже
готовые файлы для редактирования и выгружает готовые материалы в привычных форматах.

#### 2.8.1. Экспорт (из редактора)

- **HTML** — выгрузка отформатированного документа в виде веб-страницы (удобно для публикации).
- **PDF** — печать документа в PDF-файл с настройкой страницы (поля, размер, ориентация).
- **DOCX** — выгрузка в формат Word для дальнейшего редактирования в офисных приложениях.
- **Обычный текст (TXT)** — чистый текстовый файл без разметки.
- **Выборочный экспорт** — возможность выгрузить только выделенный фрагмент документа.

#### 2.8.2. Импорт (в редактор)

- **DOCX → Markdown** — открытие документа Word с автоматическим преобразованием в Markdown-разметку для редактирования.
- **HTML → Markdown** — открытие веб-страницы или HTML-файла с конвертацией в Markdown.
- **TXT → Markdown** — открытие обычного текста с корректным распознаванием разметки.
- **Предпросмотр результата** — перед окончательным открытием пользователь видит, как импортируемый документ будет выглядеть в редакторе.

#### 2.8.3. Общие особенности обмена форматами

- **Сохранение структуры** — при конвертации максимально сохраняются заголовки, списки, таблицы, стили текста и ссылки.
- **Отчёт о потере данных** — при невозможности корректно перенести какой-либо элемент (например, сложный макрос) приложение понятно сообщает, что именно не перенесено.

## 3. Описание элементов интерфейса (текущее состояние)

Ниже описано, что видит пользователь и какие действия доступны. Это **предложение для реализации**
аналогичного приложения, а не обязательная спецификация.

### 3.1. Главное меню

| Раздел | Пункты меню | Назначение |
| --- | --- | --- |
| **Файл** | Новый | Создать новый документ (Ctrl+N) |
| | Открыть файл… | Открыть `.md`-файл во вкладке |
| | Открыть рабочее пространство… | Открыть папку и показать дерево файлов |
| | Сохранить | Сохранить текущий файл |
| | Сохранить как… | Сохранить файл под новым именем |
| | Закрыть вкладку | Закрыть активную вкладку |
| | Выход | Завершить работу приложения |
| **Правка** | Отменить / Повторить | Отмена и возврат последних действий |
| | Вырезать / Копировать / Вставить | Операции с буфером обмена |
| | Удалить | Удалить выделенный фрагмент |
| | Выделить всё | Выделить всё содержимое |
| **Вид** | Обновить | Перезагрузить окно |
| | Масштаб (увеличить / уменьшить / сбросить) | Изменение масштаба отображения |
| | Полный экран | Переключение полноэкранного режима |
| | Скрыть/показать главное меню | Управление отображением меню |
| | Скрыть/показать панель управления | Управление отображением панели под меню |
| | Инструменты разработчика | Служебное окно (для отладки) |

| | Закрыть | Закрыть окно |

> **Гибкое управление видимостью.** Меню и панель управления можно скрывать независимо
> друг от друга; при этом всегда остаётся видимым хотя бы один из этих элементов
> (подробнее — в разделе 2.5).

### 3.2. Панель управления (ToolBar)

Кнопки с иконками для быстрых операций. Набор кнопок охватывает все разделы главного меню:
каждая кнопка дублирует действие соответствующего пункта меню (нажатие в панели даёт
тот же результат, что и выбор в меню):

| Раздел меню | Кнопки панели управления |
| --- | --- |
| **Файл** | Новый, Открыть файл, Открыть рабочее пространство, Сохранить, Сохранить как, Закрыть вкладку, Выход |
| **Правка** | Отменить, Повторить, Вырезать, Копировать, Вставить, Удалить, Выделить всё |
| **Вид** | Обновить, Увеличить масштаб, Уменьшить масштаб, Сбросить масштаб, Полный экран |
| **Окно** | Свернуть, Развернуть, Закрыть |

Помимо кнопок, соответствующих пунктам меню, в панели есть самостоятельная кнопка
**Панель документа** — она показывает/скрывает боковую панель документа (см. раздел 3.6).

Справа на панели отображается имя активного файла и пометка о несохранённых изменениях.

#### Настраиваемая панель

1. **Полное соответствие меню.** Каждая кнопка панели дублирует пункт главного меню.
2. **Индивидуальная настройка кнопок.** Пользователь сам решает, какие кнопки показывать
   в панели. Выбор делается в окне настройки панели (список всех кнопок с галочками)
   или в соответствующем подменю. По каждому пункту — отдельный переключатель.
3. **Кнопка показа/скрытия главного меню.** В панели присутствует кнопка, включающая и
   отключающая отображение главного меню (см. раздел 2.5 о сочетаниях видимости).
4. **Взаимодействие с разделом 2.5.** Возможны оба независимых переключателя:
   - пункт меню «Вид → Панель управления» — показать/скрыть всю панель;
   - окно «Настройка панели» — выбрать конкретные кнопки.
   Настройка панели доступна, только когда сама панель показывается.
5. **Значения по умолчанию и запоминание.**
   - По умолчанию в панели включены наиболее частые операции (работа с файлами,
     отмена/повтор), остальные добавляются по желанию — панель остаётся компактной.
   - Выбранный пользователем набор кнопок **запоминается** и восстанавливается при
     следующем запуске приложения.
6. **Группировка.** Кнопки визуально объединены по разделам меню разделителями,
   чтобы панель оставалась читаемой даже в расширенном виде.

### 3.3. Панель инструментов редактора (визуальный режим)

Набор кнопок форматирования: выбор уровня заголовка, жирный, курсив, зачёркнутый текст,
списки, создание таблицы, списки задач, вставка ссылок и цитат, вставка кода, добавление
информационных блоков (заметок), а также переключатель визуальный режим / разметка.

### 3.4. Вкладки и состояние файла

- Одна вкладка соответствует одному открытому файлу.
- Активная вкладка визуально выделяется.
- Наличие несохранённых изменений отмечается специальным значком.
- Кнопка на вкладке закрывает именно её (в текущей версии).

### 3.5. Диалоговые окна

- **Открытие файла / рабочего пространства** — выбор нужного пути, с учётом недавних файлов и папок.
- **Несохранённые изменения** — запрос подтверждения перед закрытием вкладки или приложения, если есть несохранённые правки.
- **Файл изменён извне** — уведомление и выбор: «Сохранить моё» или «Загрузить с диска».
- **Настройка панели** — выбор видимых кнопок панели управления (список с галочками).

### 3.6. Панель документа

Сбоку от области редактирования располагается сворачиваемая **панель документа**, которая
открывается и скрывается кнопкой «Панель документа» на панели управления (см. раздел 3.2).
Панель содержит вкладки:

- **Оглавление** — список заголовков активного документа (с уровнями заголовков) и быстрая навигация по ним.
- **Ссылки** — список ссылок активного документа (внешние, внутренние, якоря), по которым можно переходить.
- **Связанные файлы** — файлы, на которые ссылается документ (изображения, вложения, другие Markdown-файлы и т.д.), с возможностью их открытия.

Кнопка на панели управления включает/выключает отображение панели; активная вкладка
панели выбирается кликом по её заголовку.

### 3.7. Контекстное меню редактора

Появляется по правому клику по тексту и содержит действия:

- **выделить строку** (двойной клик / клик по полю слева от текста);
- **копировать** выделенный текст;
- **вырезать** выделенный текст;
- **вставить** из буфера обмена.

Перечисленные операции также доступны через горячие клавиши (Ctrl+C / Ctrl+X / Ctrl+V).
