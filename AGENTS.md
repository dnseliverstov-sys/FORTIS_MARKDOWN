# Инструкция для ИИ-агента: запустить FORTIS Markdown Editor

Задача — после клонирования репозитория открыть рабочее окно приложения и
убедиться, что загрузился именно настольный редактор, а не только завершилась
команда в терминале.

## Требования

- Windows, macOS или Linux с графическим сеансом.
- Git.
- Актуальная LTS-версия Node.js, не ниже 22.12.0 (`node -v`).
- Интернет при первом запуске и после изменения зависимостей.

## Первый запуск

Команды одинаковы в PowerShell, командной строке Windows и терминалах
macOS/Linux:

```bash
git clone <адрес-репозитория>
cd FORTIS_MARKDOWN
npm start
```

`npm start` — единственная команда подготовки и запуска. Она сама:

1. проверяет версию Node.js;
2. устанавливает точные зависимости из `package-lock.json`, если это нужно;
3. скачивает Electron для текущей ОС и архитектуры;
4. открывает FORTIS Markdown Editor.

Первый запуск может занять несколько минут. Следующие запускаются без сети,
пока зависимости не изменились. Терминал остаётся занят до закрытия приложения.
Человеку это не мешает; агенту следует запускать команду фоновой задачей или в
управляемой терминальной сессии.

## Запуск после обновления

Сначала закройте FORTIS, затем обновите выбранную ветку и снова выполните ту же
команду:

```bash
git pull
npm start
```

Launcher не выполняет Git-команды и не меняет ветку. Если зависимости нового
коммита отличаются, он автоматически переустановит их. На Windows работающее
приложение надо закрыть до обновления: запущенный `electron.exe` может блокировать
замену файлов.

## Как проверить, что приложение работает

Для автоматической проверки запустите приложение с локальным портом отладки:

```bash
npm start -- --remote-debugging-port=9333
```

Затем опросите страницу:

```bash
curl -s http://127.0.0.1:9333/json/list
```

В ответе должна быть цель с `"url": "fortis://app/index.html"`. Через её
`webSocketDebuggerUrl` выполните `Runtime.evaluate` и проверьте:

| Выражение | Ожидаемое значение |
| --- | --- |
| `location.origin` | `fortis://app` |
| `window.isSecureContext` | `true` |
| `typeof window.showDirectoryPicker` | `function` |
| `!!window.fortisDesktop` | `true` |
| `typeof window.katex` | `object` |
| `document.body.innerText` | непустой текст, начинающийся с `FORTIS` |

Страница распаковывается несколько секунд. Если текст ещё пустой, подождите и
повторите запрос.

Чтобы только подготовить зависимости и Electron без открытия окна:

```bash
npm start -- --prepare-only
```

## Если не запускается

| Симптом | Что делать |
| --- | --- |
| Требуется более новый Node.js | Установить актуальную LTS с `https://nodejs.org` и повторить `npm start`. |
| Ошибка установки или скачивания Electron | Проверить интернет, доступ к npm registry и GitHub Releases, затем `npm config get proxy`. |
| Windows сообщает, что файл занят | Закрыть уже запущенный FORTIS и повторить `npm start`. |
| Linux сообщает об отсутствии дисплея | Запустить из графического сеанса или выполнить `xvfb-run -a npm start`. |
| Окно открылось пустым | Подождать несколько секунд: автономная страница распаковывается при старте. |

Не открывайте `app/index.html` напрямую в браузере: это не равно настольному
приложению и отключает часть файловых возможностей и нативный экспорт PDF.
